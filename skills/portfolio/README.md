# Portfolio

Skills that turn a project's history into something you can show.

## Model-invoked

Model- or user-reachable (rich trigger phrasing so the model can reach for them).

- **[case-study](./case-study/SKILL.md)** — Write a portfolio case study of your part in a project from your own git commits across its repositories, as a single-page HTML artifact with a commit chart, diagrams and before/after numbers. Works in any agent; publishes as a Claude Artifact or a standalone page.
- **[interactive-case-study](./interactive-case-study/SKILL.md)** — Write a compact, interactive case study a visitor clicks through: a hero with four figures, then at most six sections each led by something to click, with details folded into collapsed rows. One dependency-free page for any agent or host, or a guide to port it into your own site.
