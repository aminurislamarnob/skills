# Git

Skills for moving a branch through git and GitHub.

## User-invoked

Reachable only by typing the name (`disable-model-invocation: true` and `policy.allow_implicit_invocation: false`).

- **[ship-branch](./ship-branch/SKILL.md)** — Commit the current work, push, open a pull request, merge it, and delete the branch locally and on the remote. Each step is skipped when already done, so it is safe to re-run.
