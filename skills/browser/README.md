# Browser

Skills that run a change in a real browser and turn the run into a deliverable.

## Model-invoked

Model- or user-reachable (rich trigger phrasing so the model can reach for them).

- **[browser-walkthrough](./browser-walkthrough/SKILL.md)** — Check a feature or PR end to end in your real Chrome, screenshot every step, verify the server agrees, and publish a private walkthrough page with findings.
- **[feature-video](./feature-video/SKILL.md)** — Record a feature working in a real browser, edit the takes into a captioned walkthrough video with HyperFrames, and narrate it with an ElevenLabs voice.
